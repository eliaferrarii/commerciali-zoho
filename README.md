# Commerciali Zoho

Canale di distribuzione pubblico dell'app **Commercializ** — dashboard Windows per obiettivi commerciali, avanzamento e pipeline ordini (Zoho).

## Download

Ultima versione: vedi la pagina [Releases](https://github.com/eliaferrarii/commerciali-zoho/releases).

Scaricare `Commercializ-Setup-X.Y.Z.exe` e installare.

## Codice sorgente

Il codice sorgente è privato. Questo repository contiene solo gli installer firmati e i file di update generati da `electron-builder`.
